# Textures

Grab the 2K earth textures from [Solar System Scope](https://www.solarsystemscope.com/textures/) and drop them here. They're CC BY 4.0 so free to use as long as you credit them (which we do in the project README).

Rename them to match what the code expects:

- `earth-day.jpg` — the daytime diffuse map
- `earth-night.jpg` — city lights / nightside emission
- `earth-bump.jpg` — normal map for terrain relief
- `earth-specular.jpg` — specular mask (bright = water, dark = land)
- `earth-clouds.jpg` — cloud layer, needs alpha transparency

Note: some of the textures may download as .tif format. Conversions are needed since tif is not a browser friendly format.

The 2K versions are plenty for this project. 8K looks nicer but tanks performance on weaker GPUs.
